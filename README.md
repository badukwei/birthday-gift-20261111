# 給妳的生日驚喜

手機優先的生日網站：Quokka 問問題 → 選答案 → 顯示照片 → 下一題，共五題。五題答錯皆會提示重選，答對才顯示對應照片或影片，不計分。最後一題答對後顯示合照與完整生日留言。

## 預覽

在此資料夾執行 `python3 -m http.server 5173 --bind 127.0.0.1`，打開 http://localhost:5173 。此預覽僅供本機存取。

不需要安裝套件或建置；亦可直接用瀏覽器開啟 `index.html`。

## 換成你們的內容

- `content.js`：五題問題、選項、回答後的文字、照片標題與說明。
- `correctAnswer`：正確選項索引（`0` 是第一個、`1` 是第二個），`null` 代表所有答案皆可。`wrongReply` 是答錯提示。五題已依提供的回憶設定為 A、A、B、C、C。
- `photos/01.jpg` 到 `photos/05.jpg`：放入自己的五張照片；其他檔名或格式請同步修改 `content.js` 的 `photo`。
- 第一題已使用提供的 `photos/01.png`；第二題使用 `videos/first-dance.mp4`（由原始 MOV 轉成 H.264/AAC MP4，保留聲音、長邊 1280px，原檔不變）。設定 `video` 可改用影片，支援手機行內播放、原生控制與全螢幕，不自動播放。下一題會停止播放。
- 尚未放照片時會顯示設計好的預留位置。五題內容與素材均已替換為使用者提供的回憶。
- 直橫照片皆完整呈現，不裁切。作答紀錄不會傳送至伺服器；部署後照片與影片由網站提供。

## 素材來源

DINOTAENG 官方角色頁：https://dinotaeng.com/character/

`assets/quokka.json` 與 `assets/bobo.json` 來自該頁的角色動畫，WebP 檔案為動畫內原有影格的直接解碼，未修改角色圖片。Quokka 動畫使用本地影格，不依賴外部播放程式。

角色與插畫版權歸 DINOTAENG；本專案未取得額外授權，不宣稱素材為開源或自製。Bobo 素材已備妥，目前簡化版僅使用 Quokka。

字型來自 Google Fonts；離線或載入失敗時使用裝置字型，其餘功能與角色素材均可離線使用。

第三題使用 `videos/first-trip.mp4`，由 `IMG_1835.MOV` 轉成直式 720×1280 H.264/AAC MP4，並轉換 HDR 至 BT.709；長度約 24 秒，原檔不變。

第四題使用 `videos/wedding-memories.mp4`，正確答案為「以上皆是」。原始影片已是手機適用的 H.264/AAC，因此僅另存並調整串流載入順序，未重新壓縮，保留畫質和聲音；長度約 41 秒，原檔不變。

第五題使用 `photos/third-birthday.png`，答案為「你什麼樣子我都喜歡」，結尾保留使用者提供的完整生日留言並分段顯示。
